# Working in this repository

This is a general mathematics collection. Follow CONTRIBUTING.md and docs/verification.md.

- Inspect existing results and implementations before adding another version.
- Use primary literature to establish the exact question and prior work. Separate a theorem's mathematical validity from novelty or priority.
- Preserve hypotheses, quantifiers, arithmetic domains and boundary cases during edits.
- Treat proof drafts as drafts. Do not upgrade review or formalization status without the evidence required by the catalogue schema.
- Keep application-specific material, operational logs and private inputs outside this repository.
- Use exact arithmetic for mathematical certificates. Test claims against independent small-case oracles where practical; never treat finite evidence as an unrestricted proof.
- Record negative results and counterexamples. Reconsider the construction or problem formulation when evidence contradicts it.
- Run the applicable checks, update the generated catalogue, and commit coherent, verified changes.
