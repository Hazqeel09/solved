# Questions and boundaries

The catalogue is organized around precise statements. Its initial arithmetic concentration reflects the available manuscripts; future work can add any mathematical subject.

| Research question | Primary source | Current scope here |
|---|---|---|
| Classify addition–multiplication chains with two small steps. | [Tarek, Bahig and Anwar, §7](https://doi.org/10.3934/Math.2026667) | [All-length block-classification draft](../results/two-small-steps/PROOF.md). It classifies witnesses; distinct parameters may share an endpoint. |
| Determine well-ordering and ordinal types of real AM-chain defects. | [Altman, thesis §6.2, Question 6.2.1](https://hjaltman.github.io/thesis-FIXED.pdf) | [Global-order draft](../results/am-defect-order/PROOF.md) and [slice draft](../results/am-defect-slices/PROOF.md), awaiting independent review. |
| Can subtraction yield an unbounded additive gap, or superpolynomial savings? | [Saranurak and Jindal](https://arxiv.org/abs/1212.2549) | [Additive-gap theorem with a complete Lean proof](../results/subtraction-gap/PROOF.md), pending independent presentation and priority review. Polynomial equivalence is not settled by this result. |
| How can reusable intermediate arithmetic values be synthesized efficiently? | [Alcock et al.](https://arxiv.org/abs/2011.11767), [Cantaloube et al.](https://doi.org/10.4230/LIPIcs.CP.2026.11) | [Target saturation](../results/target-saturation/PROOF.md) and restricted exact domain results, each with explicit model assumptions. |
| Is every DAG pebbling number captured tightly by a suitable visit rule? | [Bilardi and De Stefani](https://doi.org/10.4230/LIPIcs.FSTTCS.2022.7) | [One-shot register oracle](../results/one-shot-registers/PROOF.md) addresses a different, restricted scheduling problem. |
| Does the Scholz–Brauer inequality hold for every exponent? | [Clift's research page](https://www.additionchains.com/ScholzBrauer.html) | [Finite certificates](../results/scholz-finite/PROOF.md) reproduce established cases for exponents 1–59. |
| Is {0} ∪ {2^a 3^b : a,b≥0} an essential component? | [Erdős problem 1146](https://www.erdosproblems.com/1146) | [Eventually-periodic case](../results/periodic-essential-components/PROOF.md), with no conclusion for arbitrary intermediate-density sets. |

The [squaring counterexample](../results/square-instability/PROOF.md) disproves universal one-write growth and square-root closure of the defect-at-most-three endpoints. Stability for every base of defect three and root closure at defect two remain unresolved here. The [sector reconstruction](../results/root-closure-sectors/PROOF.md) eliminates three, four and seven canonical nonsquares, the GGS/GGSG/GSG event orders, and power-only histories. Every shortest chain for a remaining counterexample square must have order SGG, SGGG or GSGG and contain a value that is not a power of two. The power-only argument uses the classical low-step addition-chain classification; it does not eliminate all power-of-two endpoints. The four-event result includes a finite-menu completeness argument and an infinite family requiring helpers beyond original values and their roots. This reduction retains written-proof status and depends on the existing seven-sector classification.

The finite-control coverage arguments and the main additive gap now have complete formalizations. The [effective-cutoff follow-up](../results/effective-control-cutoffs/PROOF.md) now has a complete formal reference algorithm for bases, cutoffs and a computable universal threshold. Its exhaustive universal construction has not been numerically evaluated. Further directions include useful quantitative rates, practical threshold computation, a universal refinement proof for the optimized Python search, exact endpoint classification beyond witness families, and higher-defect squaring stability. Each needs its own statement and literature audit.
