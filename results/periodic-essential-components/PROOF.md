# An elementary eventually-periodic case of essential components

**Status: research proof draft; independent mathematical review pending.** Automated evidence is scoped below and does not certify the complete argument.

Write B₀=B∪{0} and σ for the infimum over positive prefix densities. For every finite prefix, (B₀+{0,1}) has density strictly above σ(B) if 0<σ(B)<1. Indeed either the prefix is full or its first missing element follows an element of B₀ and is gained. Strictness for each prefix does not by itself give strictness of the infimum. If the lower asymptotic density of B exceeds σ(B), the tail of the sequence is uniformly separated too. Alternatively if rightward transitions from membership to non-membership have positive lower density, they give a uniformly positive gain in all large prefixes. An eventually periodic set with both types of residues has such transitions. An eventually full set uses the first criterion, and an eventually empty set cannot have σ(B)>0. The conclusion follows by taking a minimum over the finitely many remaining prefixes. H contains 0 and 1. For a purely periodic B, each prefix ratio along a residue class interpolates between its first ratio and its limiting period mean. The verifier computes both exactly and checks all binary periods through 8. These arguments do not give a uniform gain for arbitrary B. [Exact periodic calculations](../../checks/classical.py)
