# Exact affine root domains in balanced components

**Status: research proof draft; independent mathematical review pending.** Automated evidence is scoped below and does not certify the complete argument.

**Claim C3. Written proof, exact implementation and finite differential checks.** Use the model of C1. Assume every cycle product is the projective identity. For the chosen root x, require the transported value of every vertex and every *executed prefix* on both sides of every observation to be affine over the rationals. Then the full feasible integral root domain is either empty or a single residue class intersected with an integer interval. It has a representation of constant cardinality in integers, even if it contains billions of possible values.

**Proof.** The tree gives every vertex as a function of x. Balance enforces each remaining observation as a rational identity. Represent each requested affine value, including the root and intermediate prefixes, as (a x+b)/d with d>0. Invertibility gives a≠0. Legal bounded arithmetic requires d ≤ a x+b ≤ Ld and a x+b ≡ 0 mod d. These are necessary. They are sufficient: each path operation agrees with its rational value at these integers. All actual operands are positive, so every executed division has nonzero divisor and integral quotient. The terminal operation gives its specified positive integer, so it too executes legally. Checking prefixes matters even when two exact divisions cancel algebraically.

Intersect the derived integer intervals, reversing inequalities for negative slopes. If the current congruence is x=r+m k, substitute it into a x+b ≡ 0 mod d. A solution exists iff gcd(a m,d) divides −(a r+b). Extended modular inversion yields one residue of k modulo d/gcd(a m,d). This merges noncoprime as well as coprime constraints. Intersect the resulting progression with the common interval. Each merge is polynomial in the bit length of the template and coefficients. The modulus can grow numerically as large as a product of input moduli, but its bit length is bounded by their summed bit lengths.

**Example.** With labels linked by x/6−y=1 and x/4−z=1, the positive feasible roots up to 10^18 are 12,24,…,999999999999999996. Adding a requirement that (x+1)/2 be integral makes the domain empty. The implementation returns an exact Python range. A nonlinear prefix or an informative cycle returns an explicit unsupported status for this particular compression. If a root value is selected from the range, all its dependent values are uniquely determined by the tree.
