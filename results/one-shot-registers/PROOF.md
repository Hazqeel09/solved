# Exact register requirements for a fixed one-shot DAG

**Status: research proof draft; independent mathematical review pending.** Automated evidence is scoped below and does not certify the complete argument.

Fix distinct seed and result names. Every rule executes once, including a target write that can die immediately. Inputs initially occupy distinct slots, reads precede an overwrite, outgoing values have free register placement and the selected DAG has no rematerialization. At an executed ideal I, live set S(I) consists of computed inputs/values used later or pinned for return. An enabled write v requires at least max(|S(I)|, 1+|S(I∪{v}) excluding v|) slots. This is sufficient as the write can overwrite any slot whose old value dies, including a consumed operand. Keep the other survivors in place. Minimize the maximum of this local bound and the optimal remaining peak over all enabled v by backward dynamic programming. Include the initially occupied seed slots. This is an exact exponential oracle for the model. With seeds 2 and 3 the two direct writes 5=2+3 and 6=2×3 need three registers even when both targets only need a visit. Two slots suffice in the unrestricted instruction model by writing 5 over 2, reconstructing 2=5−3 there and writing 6. Thus a one-shot rejection alone cannot eliminate a program that permits recomputation. A fixed register-exit permutation would require additional constraints.
